# Security Policy

## Supported Versions

Only the latest commit on the `main` branch is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public issue.

Instead, please send an email to the repository owner or submit a private security advisory via GitHub's "Security" tab.

### Expected Information
- A description of the issue or potential exploit.
- Steps to reproduce the issue.
- Potential impact on calculation data or user information.
